# Hotel Reservation System — Enhanced Java Swing GUI

## Features
- Dark navy header, clear tabs, and darker high-contrast action buttons
- Search rooms by dates and category (Standard, Deluxe, Suite)
- Create reservations and calculate total price
- View booking details, simulate payment, and cancel reservations
- Save booking records in `data/bookings.dat`; availability is derived from active reservations

## Run in IntelliJ IDEA
1. Extract the ZIP.
2. Choose **File → Open** and select the extracted folder.
3. Open `src/Main.java` and run the green triangle next to `main`.
4. If required, right-click `src` and choose **Mark Directory as → Sources Root**.

Requires JDK 8 or later. Payment is simulated only; this project does not use a real payment gateway or SQL database.
